## Distribution

SwiftPM only. Swift tools 6.0, Swift 6 language mode, iOS 16. Objective-C,
CocoaPods and Carthage are not supported: the Objective-C compatibility layer
(`FSPagerViewObjcCompat.h/.m`), the Objective-C example, the podspec and the
Carthage project under `FSPagerView/` were removed (see Git history before
`fix/swift-example`). The `@objc` attributes on the public API stay unchanged.

`FSPageViewExample-Swift` keeps upstream's three examples, now a Swift 6, iOS 16
app with the scene life cycle that depends on the local package. Its project is
generated by XcodeGen from `project.yml`, and `FSPagerViewExamples.xcworkspace`
opens it together with the Demo host below.

`Fixtures/DemoApp` is a maintained UIKit host (Swift 6, iOS 16) with XCUITests for
rotation, animated collapse/expand under Auto Layout and UIStackView, and an
accessibility audit. Its project is generated by XcodeGen from `project.yml`; the
generated `FSPagerViewDemo.xcodeproj` is committed so tests need no extra tools.

## Patches

See [Swift 6 migration](SWIFT6_MIGRATION.md) for every behavior-visible change.
In short: UI protocols and the transformer are main-actor isolated, the
automatic-sliding timer no longer retains the pager, the cell's font KVO uses an
observation token, the package ships a privacy manifest, resizing (rotation,
Dynamic Type, stack views) keeps the current page centered, and the cell's text
label follows Dynamic Type.

## Verify

Use Xcode and a dedicated booted iOS Simulator (no CocoaPods or app checkout):

```sh
scripts/test-ios.sh <simulator-uuid> <derived-data> -- SWIFT_STRICT_CONCURRENCY=complete
scripts/check-consumer.sh <fresh-output-directory>
scripts/test-demo-ui.sh <simulator-uuid> <derived-data>
scripts/test-swift-example.sh <simulator-uuid> <derived-data>
scripts/check-concurrency-diagnostics.sh <build-log> [...]
```

Run the library tests, the Demo UI tests and the example smoke test on each dedicated device: an iPhone, an
iPad, and an iPhone Duo (its device type ships on its own runtime,
`iOS-27-2-iPhone19-4`). Then walk through the Demo on the Duo with RocketSim, with
its live preview open, and check the screenshots.

Create the dedicated Simulator yourself (`xcrun simctl create FSPagerView-Tests …`)
and boot it before testing; the scripts never pick or boot a device. The package
regressions include collapsing the pager to zero width, height, or size and
expanding it again without losing `currentIndex`.

The package workspace under `.swiftpm` is selected explicitly because the
upstream `FSPagerViewExamples.xcworkspace` and `FSPagerView.xcodeproj` also
define an `FSPagerView` scheme without the package tests. Animated scrolling does
not render frames in an unhosted XCTest bundle, so the visible automatic advance
and transformer rendering are checked in a Simulator host app; see
[validation](VALIDATION.md).
